# SevenGen Studios

The official website for SevenGen Studios, an Indigenous-led digital studio founded by Brennan Kakakaway and Rylan Iron in Saskatchewan.

SevenGen builds community websites, digital products and clearer information systems. Our first product is [openband.ca](https://openband.ca).

## Local development

Requirements:

- Node.js 22.13 or newer
- npm

```bash
npm ci
npm run dev
```

The local development server is provided by Vite and Vinext.

## Production build

```bash
npm run build
```

Every pull request is automatically checked with the same production build.

## Working together

1. Create a branch from `main`.
2. Make one focused change at a time.
3. Run `npm run build` before opening a pull request.
4. Open a pull request and ask the other founder to review it.
5. Merge only after the automated build check passes.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full workflow.
